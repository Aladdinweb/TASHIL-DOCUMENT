Déposez ici le fichier tashil-scanner.apk (projet mobile TASHIL SCANNER,
Kotlin natif, étape 2 — pas encore développé à ce jour) une fois prêt.

Dès que ce fichier existe à cet emplacement exact, l'onglet "TASHIL SCANNER"
de l'application le détecte automatiquement (/api/scanner/status) et
affiche le QR code + le bouton de téléchargement — aucun redémarrage ni
changement de code nécessaire.
